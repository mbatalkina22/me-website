## Overview

A minimalist, single-page portfolio designed to be fast and highly interactive. It features a custom vertical accordion layout for the hero section and a clean, responsive dark-mode UI.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel
